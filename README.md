# 🛡️ K-Shield 주니어 학습 노트

한국정보보호교육센터(KISEC)의 **K-Shield 주니어** 교육을 들으며 정리한 노트입니다.
정보보안의 기반이 되는 운영체제(Linux · Windows), 네트워크, 보안 기본 개념을 다룹니다.

> 수업 중 필기한 내용을 바탕으로 다시 정리했고, 필기가 부족했던 부분은 `💡 보충` 표시로 내용을 덧붙였습니다.

## 📚 목차

| 파트 | 주제 | 주요 내용 |
|---|---|---|
| [1. Linux](01-linux.md) | 리눅스 시스템 | 실습 환경 구축, 쉘, 기본 명령어, vim, 파일 시스템·링크, 파티션·LVM, 사용자·권한, 프로세스 |
| [2. Windows](02-windows.md) | 윈도우 시스템 | 로컬 사용자·보안 정책, 공유 폴더, 서비스, 이벤트 로그 |
| [3. Network](03-network.md) | 네트워크 기초 | 통신 3요소, OSI 7계층, ARP, TCP 3-Way Handshake, 라우팅 |
| [4. Security](04-security-basics.md) | 정보보호 개론 | 보안 3요소(CIA), 정보보호 목적, 관점별 보안 용어 |
